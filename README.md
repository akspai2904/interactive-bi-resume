# Interactive BI Resume | Tableau Portfolio

## Overview
An interactive Tableau resume showcasing 9+ years of professional experience in Business Intelligence, Data Engineering, and Analytics.

This project transforms a traditional resume into a visual, interactive experience, allowing recruiters and hiring managers to explore my career progression, technical capabilities, and measurable project outcomes.

## Dashboard Features

### Career Timeline
An interactive Gantt chart illustrating my professional journey across Amazon, Capgemini, and Northern Illinois University.

### Technical Capability Matrix
A visual representation of technical competencies across:
- Business Intelligence Engineering
- Data Engineering
- Data Science
- AI & Machine Learning

### Featured Projects

- ML-Driven Seller Prioritization — ~$3M incremental GMS
- A/B Testing Framework — 26–36% incremental GMS uplift
- SQL Query Optimization — up to 90% runtime reduction
- Court Case-Delay Risk Prediction — 900K+ cases analyzed
- Student Performance Analysis — statistical modeling and machine learning
